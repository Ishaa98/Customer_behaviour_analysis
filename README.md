## 4. Project Workflow

The project was completed through the following stages:

### Step 1: Data Loading
- Imported the dataset into Python using Pandas.
- Examined the dataset structure, dimensions, and data types.
- Reviewed initial records to understand the available variables.

### Step 2: Exploratory Data Analysis (EDA)
- Analyzed data distributions and statistical summaries.
- Identified patterns, trends, and relationships between variables.
- Used visualizations to understand the dataset.
- Identified potential data quality issues.

### Step 3: Data Cleaning & Preprocessing
- Handled missing and duplicate values.
- Corrected inconsistent data formats.
- Standardized column names and data types.
- Prepared the cleaned dataset for further analysis.

### Step 4: SQL Analysis Using MySQL
- Imported the cleaned dataset into MySQL.
- Executed SQL queries to extract meaningful information.
- Used filtering, sorting, grouping, and aggregate functions.
- Applied joins and subqueries wherever required.
- Answered business-related questions through SQL analysis.

### Step 5: Power BI Dashboard
- Connected the analyzed data to Power BI.
- Created interactive visualizations and KPI cards.
- Developed charts and graphs to highlight important trends.
- Designed a dashboard to present key findings in an easy-to-understand format.

### Step 6: Report & Presentation
- Prepared a detailed analytical report documenting the methodology, analysis, and findings.
- Created a professional presentation using GAMMA.
- Summarized key insights and actionable recommendations.

## 7. How to Run the Project

Follow these steps to reproduce the analysis:

### Prerequisites
Install the following tools:
- Python 3.x
- Jupyter Notebook
- MySQL Server and MySQL Workbench
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### Step 2: Navigate to the Project Folder

```bash
cd your-repository-name
```

### Step 3: Install Required Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter
```

### Step 4: Run the Jupyter Notebook

```bash
jupyter notebook
```

Open the project notebook and execute the cells sequentially to perform data loading, EDA, and data cleaning.

### Step 5: Run SQL Queries

- Start your MySQL server.
- Create the required database.
- Import the cleaned dataset into MySQL.
- Execute the SQL scripts provided in the repository.

### Step 6: Open the Power BI Dashboard

- Open the `.pbix` file using Power BI Desktop.
- Configure the data connection if required.
- Refresh the dataset to view the dashboard.
